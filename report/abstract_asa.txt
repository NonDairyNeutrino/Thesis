Title: Using Distributed GPU-Based Parallel-in-Time Integration to Model Acoustics in Expanding Volumes

Abstract: 
One of the biggest problems in modelling the dynamics of physical phenomena is the computational cost of more and more accurate time-stepping.
The Parareal algorithm for parallel-in-time integration aims to eliminate this problem.  
For oscillatory systems modelled via PDEs, such as the wave equation, a Fourier expansion can be applied to transform the model to a systme of ODEs.
Using a distributed network of GPUs, the Parareal algorithm can be implemented for potentially massive computational speed-up.
